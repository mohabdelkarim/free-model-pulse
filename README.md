## ✨ What is this?

OpenRouter offers dozens of **free LLMs**, but which ones are actually fast? Which ones fail half the time? Which ones just appeared today?

**Free Model Pulse** answers all of that automatically:

```
 every 6 hours          every day
     ┌──────────────┐       ┌────────────────────────┐
     │ 🔍 Discovery │──────▶│ ⚡ Benchmark + Analyze  │
     │              │       │                        │
     │ fetch models │       │ run prompt on each     │
     │ detect new   │       │ measure latency        │
     │ commit snap  │       │ count tokens           │
     └──────────────┘       │ update README table    │
                            │ commit all data        │
                            └────────────────────────┘
```

One API key. One repo. Full history. No dashboards to maintain.

---

## 🗂️ Data Files

Every run commits real data back to this repo:

```
data/
├── catalog/
│   ├── current_free_models.json      ← live snapshot of free models
│   └── free_models_history.jsonl     ← append-only catalog changelog
├── raw/
│   └── benchmark_runs.csv            ← every single run (append-only)
└── derived/
    └── model_index.csv               ← aggregated leaderboard metrics
```

> **Raw is sacred.** The raw CSV is never modified, only appended. Derived files are always regeneratable.

## 🚀 Quick Start

### 1. Clone and install

```bash
git clone https://github.com/mohabdelkarim/free-model-pulse.git
cd free-model-pulse
pip install -r requirements.txt
```

### 2. Set your API key

```bash
cp .env.example .env
# Add: OPENROUTER_API_KEY=sk-or-...
```

### 3. Run locally

```bash
# Discover what is free right now
python watch_models.py

# Benchmark all of them
python benchmark.py

# Generate leaderboard, refresh README, write Pages
python analyze.py --min-runs 1 --update-readme --write-pages
```

### 4. Deploy to GitHub Actions

Add a single secret to your repo:

| Secret | Value |
|--------|-------|
| `OPENROUTER_API_KEY` | `sk-or-...` |

That is it. Both workflows start running automatically.

Live Pages mirror: https://mohabdelkarim.github.io/free-model-pulse/

## 🔧 GitHub Actions Workflows

### `model-watch.yml` (every 6 hours)

1. Fetches all models from OpenRouter
2. Filters for free, non-router models
3. Detects catalog changes vs history
4. **Always commits** `data/catalog/` to the repo

### `benchmark.yml` (daily at midnight UTC)

1. Runs unit tests first
2. Refreshes catalog
3. Sends the benchmark prompt to every free model
4. Measures latency + tokens
5. Aggregates into `model_index.csv`
6. **Updates this README** with the live leaderboard table
7. Writes `docs/index.html` for GitHub Pages
8. Commits everything: `data/` + `README.md` + `docs/`

## 📐 Metrics Explained

| Metric | What it means |
|--------|---------------|
| **Success rate** | % of runs that returned a valid response |
| **Median latency** | Typical response time (seconds) |
| **P95 latency** | Worst-case response time (95th percentile) |
| **Tokens/sec** | Generation speed |
| **Total runs** | How many times this model has been benchmarked |

> ⚠️ **This is operational data, not a quality ranking.** Latency ≠ intelligence. A slow model can be smarter than a fast one.

## 🧠 Design Principles

1. **No hardcoded model lists.** Discovery is 100% dynamic from the API.
2. **No `openrouter/free`.** Each model is benchmarked individually for accurate attribution.
3. **Append only data.** History is never rewritten; derived data is always regeneratable.
4. **Single runner per workflow.** Avoids data loss between GitHub Actions jobs.
5. **Fail gracefully.** One model timeout does not kill the entire run.

## 📦 Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `OPENROUTER_API_KEY` | ✅ | (required) | Your OpenRouter key |
| `OPENROUTER_SITE_URL` | ☑️ | (none) | Optional: shown in OpenRouter dashboard |
| `OPENROUTER_SITE_EMAIL` | ☑️ | (none) | Optional: contact for OpenRouter |
| `BENCHMARK_TIMEOUT_SEC` | ☑️ | `120` | Per-model request timeout |
| `BENCHMARK_MAX_RETRIES` | ☑️ | `3` | Retries on rate limit / server error |

---

## ⚖️ Limitations

1. Free models are frequently **rate limited**. Failures may reflect OpenRouter load, not model quality.
2. Latency includes **GitHub Actions network variance** (~50 to 200ms).
3. Benchmarks use **one prompt**. Results may not generalise to your use case.
4. The free catalog **changes without notice**. Models appear and disappear.
